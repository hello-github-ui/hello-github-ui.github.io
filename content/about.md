## 关于我

你好，我是 **QiYue**，一名技术探索者。

这个博客是我的个人技术笔记和随笔空间，主要记录在 Linux 运维、数据库管理、开发工具使用等方面的实践经验。

## 技术栈

- **Linux 运维**：CentOS、Linux Mint 等发行版的安装与配置
- **数据库**：MySQL、Redis 的部署、配置与优化
- **开发工具**：Git、Hugo、Pages CMS 等
- **部署方案**：GitHub Pages + GitHub Actions 自动化部署

## 关于这个博客

这个博客使用以下技术栈搭建：

- **Hugo** — 静态站点生成器，极速构建
- **Blowfish 主题** — 现代、灵活的 Hugo 主题
- **Pages CMS** — 基于 Git 的可视化内容管理
- **GitHub Pages** — 免费托管与自动部署
- **GitHub Actions** — CI/CD 自动化构建

所有文章内容完全属于我自己，存储在 Git 仓库中，可随时迁移。
